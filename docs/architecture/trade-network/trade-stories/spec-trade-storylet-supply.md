# Spec: `trade-storylet-supply`

**Status: written 2026-09-19 against the approved map** ([trade-stories-map.md](../trade-stories-map.md),
APPROVED 2026-09-19, module 10, wave 2). Every `file:line` below was opened this session. Docs only.

## Objective

The contract between trade and the one content generator, stated so no trade storylet is ever written
outside it. Trade supplies **facts and hosts**; storylet rows are emitted, validated and regenerated by
narrative-seed's `narrative` adapter (narrative-seed-ideal §6.1: *one storylet generator for every place*).
This module is a set of asks with acceptance; it writes no seed file.

## Locked anchors

- **No second storylet generator** (trade-network ideal §14b; narrative-seed-ideal §6.1).
- **Generated data is never hand-edited** (CLAUDE.md hard rule): a defect in a trade storylet is fixed in
  the generator and regenerated.
- **Owner decision OD-3 (2026-09-19): narrative-seed owns the host-kind list.** The four trade host kinds are
  rows in `storylet-vocab`'s `host-kinds.v1.json` ([spec-storylet-vocab.md](../../narrative-seed/spec-storylet-vocab.md) §3.1).
- **Closed runtime slots:** `{place}`, `{supply}`, `{reward}`, `{cost}`
  ([spec-token-grammar.md](../../narrative-seed/spec-token-grammar.md) §4); a new slot is a reviewed
  widening. **No digit in seed text** — magnitudes come from the runtime.

## What already exists

The registries and adapter are specced, unbuilt (`narrative-seed-map.md` modules 5, 8, 10, 16, 18);
`gk-data/packs/fusion/data/seed/narrative/` does not exist yet. No trade host is in any registry.

## Design — the asks

| # | Ask | Owner module | Recommendation |
|---|---|---|---|
| S1 | Four host rows: `world.trade-hub`, `world.depot`, `world.trade-lane`, `world.trade-turn` (place `world`, clock `world.turn`) with `admits` | narrative-seed `storylet-vocab` | `admits` as in `spec-trade-hosts.md` §1 |
| S2 | Runtime slots for goods, routes and counterparties | narrative-seed `token-grammar` | Prefer mapping onto existing slots: the good as `{supply}` when spent, `{reward}` when gained, the route and counterparty as `{place}`. Only if the grammar owner refuses, add `{good}`, `{route}`, `{counterparty}` as a reviewed widening |
| S3 | Coverage cells host kind × storylet kind × climate for the four hosts in the planner's budget file | narrative-seed `narrative-planner` | one cell per (trade host, admitted kind); climate-neutral for `world.trade-turn` |
| S4 | Choice patterns using `offer`, `fight` and `bring` on trade hosts | narrative-seed `storylet-vocab` (patterns) | `[offer, leave] + use` at hubs (buy your way out), `[fight, leave] + bring` on lanes (an ambush) |
| S5 | Condition vocabulary rows for the four trade leaves (`WarehouseFillAtLeast`, `PriceBandIs`, `AccessIs`, `TreatyIs`) and, if accepted, `StoryFactWithin` | narrative-seed `storylet-vocab` (conditions) | one condition row per leaf, values from the leaf's closed domain |
| S6 | Trade roles already in the closed role list: `trader`, `envoy`, `clan-elder` | none (already present, `spec-narrative-vocabulary.md` §1) | used as-is |
| S7 | Arc shapes for the three failure branches (`trade-failure-branches` §2) | narrative-seed `arc-shapes`, `arc-pipeline` | 3-link shapes, `world.trade-turn` host per link |

## Contract exposed

The asks above. Consumer: narrative-seed.

## Acceptance (contract level)

1. Every trade host kind has at least one coverage cell in the planner's budget file (a join, not a count).
2. No file under `gk-data/packs/fusion/data/seed/narrative/**` is authored or edited by trade-stories (guard: no trade-stories
   spec lists that tree in its touched paths; a CI diff check on trade-stories changes).
3. Every trade leaf has a condition row, or its absence is listed as pending in `trade-trigger-reachability`.
4. Every trade storylet the adapter emits passes the runtime preflight, including
   `storylet.unreachable-trade-trigger` (`trade-trigger-reachability` §3).

## Test plan and verification boundary

narrative-seed's seedsmith tests own the registry and corpus checks; this spec's own boundary is
`docs-and-assistant-config` (`docs/**`). The join in acceptance 1 runs in seedsmith's metrics
(`narrative-metrics`).

## Hard edges

- Blocked on narrative-seed modules 5, 8, 10, 16 and 18.
- Slot widening (S2) is the grammar owner's decision; the mapping default needs nothing new.

## Dependencies

`trade-hosts`, `trade-predicates`, `trade-failure-branches`; narrative-seed `storylet-vocab`,
`token-grammar`, `narrative-planner`, `arc-shapes`, `arc-pipeline`, `narrative-metrics`.

## Boundaries

- **Always:** asks with recommendations; content from the adapter.
- **Ask first:** any new slot or role.
- **Never:** author or edit a seed row; a trade-only generator.
