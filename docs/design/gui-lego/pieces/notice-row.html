notice-row

ERM Row — one notification. Three states on payload.state (unread / read / dismissed); severity and state are both carried by text as well as colour (never colour alone). Title and body arrive already translated from renderNotification — this piece authors no sentence. Spec: docs/architecture/gui-lego/spec-notice-row.md. Proposed by the notification-ssot program's notices recipe (NS6.8); the rung is the existing Row rung (channel-row is the precedent), not a new density.

Structure (live)

● Unread · important · with a target important unread

Body text from the translator.

Read · routine · no target routine read

Body text from the translator.

Dismissed

Sample payload

{
  "piece": "notice-row",
  "instanceId": "notice:world:w1:t4:e0",
  "dedupKey": "world:w1:t4:e0",
  "category": "loam.shortfall",
  "severity": "important",
  "state": "unread",
  "title": "Shortfall",
  "body": "…translator sentence…",
  "target": { "refKind": "sector", "id": "ember-hollow" },
  "actions": ["read", "dismiss", "target"]
}

`actions` is derived from `state` (unread ⇒ read/dismiss; read ⇒ dismiss; dismissed ⇒ reopen) plus whether a target-action resolver is registered for `target.refKind`. `title`/`body` are `renderNotification`'s output; the row never sees an engine token.
