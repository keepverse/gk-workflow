story-actor-sprite

An actor's sprite, or an honest labelled shape carrying the actor's name when the art is missing. Owner decision 2: never a blank, never a broken image, never one shared placeholder for two different people. Spec: docs/architecture/story-scene/spec-actor-sprite.md.

The three cases, side by side — note that the two missing actors are distinguishable (name, initial, and pack accent), which the old shared ◈ was not.

Landmarks and rules

.story-actor-sprite                  root; carries the pack's css custom properties
  .story-actor-sprite__art           the <img> when a URL resolved
  .story-actor-sprite__placeholder   shown instead, when art/variant is missing
    .story-actor-sprite__initial     the actor's initial (ActorFrame's visual language)
    .story-actor-sprite__name        the actor's displayName  ← the "honest" half
    .story-actor-sprite__hint        "art not yet authored"
  • spriteUrl === null ⇒ placeholder. Never an <img> with an empty or unresolved src.
  • An onError load failure degrades to the same placeholder, so a broken URL cannot paint a broken glyph.
  • phase: empty for "not authored" — error is reserved for a genuine failure.
  • Paint comes from themeResolved.paint; a neutral fallback still labels the actor.
  • No side-axis tint: neither actor is a plant or a zombie.
