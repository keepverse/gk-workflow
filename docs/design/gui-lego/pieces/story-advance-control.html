story-advance-control

One piece owning both verbs of a scene — advance and skip — plus their pending and error states, so a scene never hand-rolls a footer. Spec: docs/architecture/story-scene/spec-advance-control.md.

Skip is present on every beat, including the last (owner decision 5): no first-scene nudge, no confirmation dialog. The narrative source's own rule — "Skipping never loses Souls, grants, content, or future story access" — is why gating it would be dishonest.

Normal beat

Primary label only changes on the last beat; skip never moves.

Last beat — skip still present

On the last beat the primary completes the scene; skip resolves through the same terminal path, so skipping can never leave half-written state.

Pending — both verbs disabled

Pending is the visible half of the double-click guard: the primary shows the in-flight label and both verbs are disabled.

Error — recovery, and the lawn stays reachable

We couldn't save that just now — try again next time, or carry on to the lawn.

The error branch is a variant, not a fork: the player can still reach the lawn without a successful acknowledgement, so a failed save is never a dead end.

Structure and rules

.story-advance-control
  .story-advance-control__skip      ghost / secondary
  .story-advance-control__primary   Next | Anchor the lawn
  .story-advance-control__recovery  retry + bypass (error variant)
  • Both verbs live in one piece; there is no second footer grammar.
  • Labels come from the payload — no player-visible string is hard-coded here.
  • The piece registers no keybinding: Enter/Space advance belongs to the stage on the focused body, and the keymap forbids F10.
  • Touch targets meet the kit minimum (44px) at the narrow breakpoint.

Sample payload

{
  "piece": "advance-control",
  "instanceId": "scene:advance",
  "phase": "ready",
  "isLastBeat": false,
  "nextLabel": "Next",
  "finalLabel": "Anchor the lawn",
  "skipLabel": "Skip intro",
  "pending": false
}

Error variant adds error: true, retryLabel and bypassLabel. Pending adds pending: true and pendingLabel.
