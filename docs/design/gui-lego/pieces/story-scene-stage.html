story-scene-stage

The compose root: full-bleed art bed, band-utility stacking, the cue state the whole scene reads, and the two-actor responsive layout. It owns composition and geometry — never actor identity, copy, or paint. Spec: docs/architecture/story-scene/spec-scene-stage.md.

Structure and rules

.story-scene-stage               root; scene pack css + data-cue + data-motion
  .story-scene-stage__backdrop   flat bed colour (behind everything)
  .story-scene-stage__heading    shell title + subtitle (player text, pinned, flex none)
  .story-scene-stage__art        composed illustration; aria-hidden when a line is present
  .story-scene-stage__actors     -> actor-portrait[] (ordered array)
  .story-scene-stage__window     -> dialogue-window
  .story-scene-stage__progress   -> scene-progress (fold omits when total <= 1)
  .story-scene-stage__advance    -> advance-control
  • Direct children stay direct — no wrapper between root and slot child (child combinators).
  • data-cue is the FE's own rendering contract, never an engine handle; the cue id is never rendered as text.
  • Full-bleed never scrolls: the art bed scales down before the window or the advance control. An unreachable advance control would trap the player.
  • prefers-reduced-motion makes beat transitions and sprite swaps instant.
