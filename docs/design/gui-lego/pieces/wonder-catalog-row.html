wonder-catalog-row

Catalog row — one buildable Wonder (identity piece, live cap-count line, locked teasers as peers). Consumed by the wonder-composer recipe; mount binds foldWonderComposerVm.catalogRows. Rows lead with price + requirement (relic count + nights); details behind the select. An unbuildable row names its blocker on the control (GG-55). Authored name only — never the raw id (GG-62). Scope/rarity badges declare pack slots (wonder-scope-* / wonder-rarity-*, owned by 4D.4 — referenced by contract, never painted here). Common never renders a painted-full gauge (GG-64).
