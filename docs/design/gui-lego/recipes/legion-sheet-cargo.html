Recipe rules (no new strings)

Tabs closed: overview (default) + cargo. Future tabs
by reservation only — never snuck into this recipe.
Per-legion reset: switching legions returns to
overview; rail-collapsed persists (new key family).
Close (Esc / ✕ / empty-map deselect) never clears the
pending queue (turn-scoped, not sheet-scoped).
Lifecycle: loading = phase-loading; unknown legion =
phase-error + retry; known-empty = phase-empty + next
action (load from stash / march to cache).
Search filters folded rows by name only; refused rows
stay visible with reason (XCOM lesson).
Buttons never disable silently (GG-55): known-
unfilable stays enabled and answers with the refusal
sentence, or carries inline reason where fold knows
it (full packs). Filing ≠ resolving (GG-15): filer
answers filed/replayed/refused-at-submit; report +
read-backs answer moved/refused/partially-fit.
One scope: exactly one GET .../cargo per open /
selection / commit-advance; never empire-wide.
Weight never on wire; capacity never recomputed
client-side; no "fit N more" prediction; no id
prettify; no position compare; no engine words.
