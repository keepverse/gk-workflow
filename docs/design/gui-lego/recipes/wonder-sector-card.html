Recipe rules (no new strings)

Built renders name + badges + effect, no progress
slot; under-construction renders name + rising
sentence + the shared meter (capacity-meter
[progress] by name — never a forked twin).
Unique renders the live cap line from
WonderPolicy numbers; Common renders no cap
line (uncapped by construction). Pre-catalog
cap reads render the designed pending state —
never a guessed number, never a hidden row.
Reserved scopes render as locked teasers with
the catalog reason — never hidden, never
buildable. Wire reasons map to catalog copy +
next action (refusal toasts shared with the
composer); nothing is consumed on refusal.
Unknown ids render the placeholder + the
card.expand reading action — never the id.
Paint arrives from wonder-scope-*/wonder-
rarity-* packs only; copy arrives from the
display catalog only; the fold formats
magnitudes and invents none.

Pack ids use exact wire case (Sector, not
sector) so the fold maps wire to paint with
no case-folding. Every member: css + paint
hex + vfx (nulls — GG-32 reduced-motion).

Refusal rows (wire reason → copy + next action)

  this land already holds all it can /
  raise no further Wonders of this kind,
  or pick another ground

  the foundation was not laid in the asked
  count of treasure / re-lay the exact count
relic.not-reachable →
  that treasure isn't here / move the
  treasure within reach first
build.cannot-afford-materials →
  the stores are short of stone and
  ironwork / gather stores, or choose
  a lesser work
Every refusal appends: nothing was taken.
