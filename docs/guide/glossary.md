# Glossary

Player words only. If a term is not here, it does not belong on a player surface.

---

## Loops (product vision)

| Term | Meaning |
|---|---|
| **Spine loop** | What you always grow — power, summon/fusion, items |
| **Place loop** | Where you play — lawn, expeditions, farm/hunt/defend, map, stage, delve, quests |
| **Level up and power** | The Garden Keeper’s level, specimen XP, aptitudes — endless, no cap |
| **Summon and fusion** | Altar, pacts, fusion, wild joins, capture |
| **Item collection** | Find, vault, equip, craft relics |
| **Idle expeditions** | Dispatch spare creatures; wait; collect — core forever |
| **Farm / hunt / defend** | Yield and materials; prey and capture; Seat and homeworld |
| **World-map adventure** | Where you go — fog, march, claim |
| **World-stage empire** | Where you stand to run the empire |
| **World virtual turns** | End Turn resolves everyone’s orders — the world clock, not a diary |
| **Quest log** | Track quests and events as a layer (**Vision**) |
| **Enemy counter-development** | The war shifts from how you play (**Vision**) |
| **Failure branches** | Loss opens different content, not only a wipe (**Vision**) |
| **Build preset** | Saved synergy loadout (**Vision**) |
| **Party formation** | How the pack stands; combo skills when you play (**Vision**) |
| **Named reaction / combo recipe** | Learnable interaction on top of the element ring (**Vision**) |

See [The loops](the-loops.md).

## Places

| Term | Meaning |
|---|---|
| **Sanctum** | Your home hall. Session start and every run return here |
| **Lawn** | A lawn match (Fusion on your machine) — the first core loop |
| **Rift / world map** | Adventure stage: sectors, lanes, legions |
| **World stage** | Empire surface over the map — HUD, inspector, End Turn (**Vision** as a finished place) |
| **Sector** | A node on the rift — ground you can claim, develop, or lose |
| **Homeworld** | The Garden Keeper’s capital sector. Losing it is losing the world |
| **Domain** | A found place you enter as a delve (**Vision**) |
| **Delve** | A party crawl through rooms to a boss (**Vision**) |
| **Siege** | Defend or assault the Seat on a tactical board (**Vision**) |
| **Battle** | Turn-based fight stage (**WIP** as something you play yourself) |

## People and creatures

| Term | Meaning |
|---|---|
| **Summoner** | You — the Garden Keeper, running the war from the Sanctum |
| **the Garden Keeper’s level** | The main power line and the Vision unlock clock |
| **Creature** | Anything in your collection layer |
| **Specimen** | One persistent individual — not a stack of copies |
| **Legion** | A force you march on the rift |
| **Commander** | Who leads a lawn run or a legion |
| **Warden** | Designed: a commander and legion stationed to defend a world you have left — costs upkeep, never freezes decay. The shipped per-sector bind (**WIP**) is being retired |
| **Advance** | Move on to a new world at any time, carrying legions and cargo up to a carry limit — larger after a win (designed) |
| **Developing** | A world whose dominant enemy empire's seat you took; it keeps running (designed) |
| **Hibernating** | A world you left; it catches up on End Turn, coarsely, when you look (designed) |
| **Idle** | A world you left with a warden stationed; it runs on the expedition clock, capped (designed) |
| **Fallen** | A world whose seat enemy empires took; hostile ground you can revisit, and your save continues (designed) |
| **Patron** | The one creature whose element colours the army (**WIP** on the live lawn) |
| **Demon** | **Not used in the shipped game — reserved for a future race.** A creature of a *new empire*, a faction in its own right. Named only; owner: *"needs a serious huge program."* Every player-facing and source use of the word is now **Creature** (repo-wide rename, 2026-09-12). Do not reintroduce it for an existing creature. See [species-selection-ideal.md](../architecture/species-selection-ideal.md) |
| **the Rotwright** | The enemy commander. He decides from his own fog |

## Verbs

| Term | Meaning |
|---|---|
| **Summon** | Spend souls at the altar for a new creature |
| **Bind / pact** | Assign a creature to a contract slot and keep loyalty |
| **Tribute** | Keep a pact paid; overdue tribute is leverage |
| **Fuse** | Merge specimens — stars, recipes, inheritance |
| **Deploy** | Send a bound creature into a lawn run or a fight |
| **Dispatch** | Send a squad on an expedition |
| **Recall** | Pull an expedition home early for pro-rated rewards |
| **Collect** | Claim expedition (or other) rewards when ready |
| **Farm** | Hold ground and take yield — no market, no conversion into loam |
| **Hunt** | Prey, capture, wild joins, delves, map fights |
| **Defend** | Hold the Seat and homeworld against Fracture and siege |
| **March / claim** | Move a legion; take a sector |
| **Cede** | Give up a sector on purpose (**WIP**) |
| **Extract** | Leave a delve with the haul (**Vision**) |
| **End Turn** | Commit orders on the world map so everyone’s **virtual turn** resolves |

## Currencies and meters

| Term | Meaning |
|---|---|
| **Souls** | Player stock — summons, contracts, rituals. Banks across worlds |
| **Essence** | Element-matched materials for fusion (and some buildings). Banks |
| **Loam** | World stock — holding and building ground. Never banks |
| **Rubble** | World stock — bulk construction material. Never banks |
| **Ironwork** | World stock — worked construction material, refined from rubble. Never banks |
| **Recruits** | World stock — builds toward raising a legion at a Seat. Never banks |
| **Materials** | Shards, substrates, and catalysts — what crafting and fusion spend besides essence. Bank |
| **The Fracture** | The force that unmakes unanchored ground |
| **HP** | Health |
| **Stamina** | Body fuel for actions (actor meter — not a play-session stamina gate) |
| **Sun / Hunger** | Plant label / zombie label for the same hunger meter — not the lawn sun bank |
| **Spirit** | Nerve and affliction pool |
| **Yang / Yin** | Plant / zombie labels for qi — buff and stance fuel |
| **Poise** | Guard pool (**WIP**) |

## Combat and build

| Term | Meaning |
|---|---|
| **Element** | Fire, ice, air, earth, light, dark (plus omni as baseline) |
| **Ring** | Fire → ice → earth → air → fire |
| **Shield** | Element-typed absorb before HP |
| **Status** | Timed condition — butter, freeze, chill, poison, wither, contagions, … |
| **Aptitude** | One of twelve free-build stats. **You have no class** |
| **Posture** | Region of build space (Force, Finesse, Bastion) — not a lock |
| **Aura** | Continuous side-wide presence from a commander (**WIP**) |
| **Relic** | Gear in your vault |
| **Almanac** | Reference — types, elements, statuses, recipes you have met |
| **Chronicle** | Your history — runs, XP, progression |
