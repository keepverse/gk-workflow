## The class

`MaterialClass.Assurance` (7th member, after `Trophy`). Three closed ids —
`assurance.assure`/`.protect`/`.repair` — via a new `AssuranceVerbs` list (the same shape
`CatalystVerbs` already has for its own closed three) and a `AssuranceIds`/`IsAssuranceId` pair
mirroring `IsTrophyId`'s own shape, but NOT host-injected: a small, permanently closed set baked
into the assembly, never reconfigured at runtime. `IsIssuable`/`ClassOf` both gained the third
OR-branch; `MaterialCatalog.All` (the 27) is untouched — Assurance's ids are counted nowhere in it,
matching the acceptance criterion's own "the five shipped classes still generate 27" verbatim.

`CostClassMatrix.Allows`'s new arm is deliberately narrow: `Temper` only (T43/T44 extend it to the
decaying verbs and `Repair` — neither is this task's own ask to answer).
