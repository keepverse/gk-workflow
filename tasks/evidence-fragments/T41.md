## The mechanism

`EnhanceContext` gains `AssureLoaded` (int, default 0) — the same "player's per-attempt choice, not
a persistent property" posture `WardLoaded` already holds, so D26 stays a property of the shape, not
a reviewer's vigilance. `EnhancePolicy.Resolve` gains an `assureBonusMilli` parameter (a raw int, not
a whole tuning object — the same "Core takes only the specific number it needs" precedent
`RepairPolicy.Resolve`'s `destructionChanceMilli` already sets). Widened before multiplying
(`(long)ctx.AssureLoaded * assureBonusMilli`); a sum past 1000 refuses by name
(`enhance.assure-overloaded`, inside the already-registered `enhance.*` namespace) rather than
silently clamping and wasting the excess; a sum at or below 1000 is what
`EnhanceAttempt.SuccessMilli` reports and the roll actually uses.

## `CraftAssuranceTuning` / `CraftAssuranceTuningHub`

A strict loader mirroring `EnhancementTuning`/`MaterialTuning`'s own idiom exactly: two required
per-mille ratios in `[0, 1000]`, no defaults, a missing or out-of-range key throws naming itself.
`RepairCoverageBonusMilli` is authored and validated now but has **no reader** in this commit — T44
is its own consumer, the same "wire it now, real callers catch up later" posture this codebase
already uses for `RecipeContext.TrophyStock` and `ItemWorkbench`'s own many optional delegate
parameters. `CraftAssuranceTuningHub` mirrors `DeploymentHierarchyTuningHub`'s own re-assignable
(never throw-on-second-call) shape, so T42/T44 can read `CraftAssuranceTuningHub.Tuning` directly
without another `Program.cs` change.

`gk-core/data/tuning/craft-assurance.v1.json`: `assureBonusMilli: 50`, `repairCoverageBonusMilli: 50` — both
decided by principle (5% per charge), not asked: `AssureLoaded` is authored as a COUNT so the
mechanic is meant to let several charges progressively de-risk an attempt rather than one charge
solving it outright; both keys start at the SAME rate for symmetry since T44 has not yet named a
reason to diverge them (documented in the file's own `Note` fields, a balance pass's own future
edit). `EnhancePolicy.cs`'s own doc comment on `Resolve` cites `Program.cs`'s literal load line so a
reader can jump straight to the wiring.
