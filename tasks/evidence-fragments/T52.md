## The publish.py probe found a second defect, and it is filed

Setting a **list-valued** key through `publish.py set` does not refuse — it stores the JSON **array as a
string**. Measured: `set-topology "resolutionOrder=[\"unique-species\",\"family\",\"general\"]"` published
a v2 whose `resolutionOrder` was the string `'["unique-species","family","general"]'` and reported one
change. That would corrupt this very file, whose `resolutionOrder` and `memberRoleSet`s are lists.
The probe's v2 was **deleted before any commit** (`git status gk-core/data/tuning` is clean, v1 byte-intact,
`tuning-immutability` guard green), and the defect is filed as **T57**.
