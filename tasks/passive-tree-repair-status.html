1 · What it is

The passive tree binds ~a third of its nodes and none of them do anything in play: the binder emits stat.modify atoms while the resolver reads only stat.derived, mechanism tiers (8–10) bind at ~2%, and 95 of 125 atom families refuse to expand. The program repairs the pipeline — expander → binder → resolver → live proof — then rebalances against it. The tree is an atom-effect container, not the runtime: this program touches container code and tuning data, never atom runtime semantics.

Ladder principle (binding): every number is f(Θ) — linear for contests (parity invariant), P(Θ) for magnitudes. Modifiers transform f(Θ); Replace substitutes a constant and is excluded by principle, not carried. Pins anchor the function; they never replace it.
